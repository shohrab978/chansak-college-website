# Chandpur Government College website

Responsive bilingual website starter. English is the default language; use the language switcher for Bangla.

## Run locally
1. Install Node.js 20 or newer.
2. Run `npm install`
3. Run `npm run dev`

## Publish
Push this folder to a new GitHub repository, then import that repository in Vercel.
Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Important
College-specific facts, contact details, notices, staff names and dates are placeholders until verified. This package does **not** include a secure admin panel, database, or live publishing workflow yet. Do not enter real passwords or private information into this demo.
